# Zs.: Unendlichdimensionale Räume

Hat jeder Vektorraum eine Basis $\Rightarrow$ ja!

Sei $K$ ein Körüer, $V$ ein $K$-Vektorraum
	***Basis = Lineare unabhänhig + erzeugend***

Eine Teilmenge $X \subset V$ ist linear unabhängig, wenn jedes *endliche* System $v_{1}, \dots, v_{k}$ aus *verschiedenen* Vektoren aus $X$ linear unabhängig ist. 
Die Menge $X$ ist erzeugend, wenn $V = \text{Lin}(X)$ gilt, wenn also jeder Vektor aus $V$ eine *endliche* Linearkombination von Vektoren aus $X$ ist. 

>[!example] Bsp.
>$$K[x]= \left\{  f = \sum _{i = 0}^n a_{i}x^i \vert a_{0}, \dots, a_{n} \in K, n \in \mathbb{N} \right\}$$
>Polynomraum hat die Basis $1, x, x^2, x^3, \dots$ 

Was ist mit $K^\infty = \{ (a_{i})_{i \in \mathbb{N}} \vert a_{i} \in K \}$, dem **Folgenraum**?
Für die "Einheitsvektoren" gilt: $$e_{j} = (a_{i})_{i \in \mathbb{N}} \text{ mit } a_{j} = \begin{cases} 1 \text{ für } j = i \\ 0 \text{ sonst } \end{cases}$$$$= (0, \dots, 0, 1, 0, \dots, 0) \implies e_{1}, e_{2} \text{ linear unabhängig}$$***Aber:*** noch nicht erzeugend und somit keine Basis.

***Erinnerung:*** ist $X \subseteq V$ linear unabhängig und $\text{Lin}(X)\subset V$, dann is t$X \cup \{ v \}$ für jedes $v \in V$ linear unabhängig.

$$\boxed{ \text{dim}(V) < \infty \implies \text{Existenz einer Basis} }$$

# 1.1 Physikalische & mathematische Grundlagen

***Einheitspräfixe*** dienen der *Vermeidung vieler Vor-/Nachkommastellen*.

| ***SI-Präfix*** | **Name** | **Symbol** |
| --------------- | -------- | ---------- |
| $10^{-12}$      | *Piko*   | $p$        |
| $10^{-9}$       | *Nano*   | $n$        |
| $10^{-6}$       | *Mikro*  | $\mu$      |
| $10^{-3}$       | *Milli*  | $m$        |
| $10^3$          | *Kilo*   | $k$        |
| $10^6$          | *Mega*   | $M$        |
| $10^9$          | *Giga*   | $G$        |
| $10^{12}$       | *Tera*   | $T$        |
